# WhatsApp Translator

Самостоятельный веб-клиент WhatsApp с переводом **русский ↔ язык собеседника** через Groq. Один WhatsApp-аккаунт; браузер на Windows и Android. **MVP**, неофициальная интеграция Baileys.

## Требования

Ubuntu Server 24.04, sudo, `curl`, `tar`, `ss`, домен с DNS на VPS, HTTPS и ключ [Groq API](https://console.groq.com/keys). Для небольшой нагрузки ориентир — 2 ГБ RAM и SWAP. Репозиторий публичный.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/Alex66166/Whatsapp-translator/main/bootstrap.sh -o /tmp/wa-bootstrap.sh && sudo bash /tmp/wa-bootstrap.sh
```

Мастер выполняет аудит VPS, предлагает параметры и требует окончательное подтверждение `INSTALL`. Указываются локальный порт приложения, внешний HTTPS-порт, домен, пароль (от 6 символов) и ключ Groq. При наличии Nginx/Apache/Caddy доступно подключение к существующему HTTPS-серверу; нестандартные конфигурации требуют ручной настройки. Настройки, база и сессия хранятся на VPS.

После установки открыть `https://ваш-домен` (при нестандартном порте — `https://ваш-домен:порт`), войти и привязать устройство: WhatsApp → **Связанные устройства** → сканирование QR-кода.

## Обновления

**Обычное обновление** — сохраняет WhatsApp-сессию, сообщения, изображения, `.env` и HTTPS. Можно оставить текущий внешний порт клавишей Enter.

```bash
curl -fsSL https://raw.githubusercontent.com/Alex66166/Whatsapp-translator/main/upgrade.sh -o /tmp/wa-upgrade.sh && sudo bash /tmp/wa-upgrade.sh
```

**Обновление со сбросом контактов** — дополнительно удаляет сохранённые имена и список контактов. Сессия, сообщения и фото сохраняются.

```bash
curl -fsSL https://raw.githubusercontent.com/Alex66166/Whatsapp-translator/main/upgrade.sh -o /tmp/wa-upgrade.sh && sudo bash /tmp/wa-upgrade.sh --reset-contacts
```

**Только сброс контактов**, без обновления приложения:

```bash
sudo bash /opt/whatsapp-translator/reset-contacts.sh
```

**Резервная копия / восстановление** — интерактивные скрипты с паролем шифрования:

```bash
sudo bash /opt/whatsapp-translator/backup.sh
sudo bash /opt/whatsapp-translator/restore.sh
```

## Контакты и сообщения

Слева отображаются **до 20 последних личных чатов**, известных Baileys. История старой переписки не импортируется. Для новых контактов **«Перевод» включён по умолчанию**; его можно выключить в конкретном чате. Доступен выбор из 20 языков, включая черногорский. Без галочки сообщения отправляются в оригинале.

Удаление контактов **из интерфейса** (после установки актуальной версии):

- **Один контакт:** выбрать его слева → **Убрать контакт** → подтвердить.
- **Все контакты:** слева **Очистить список контактов** → ввести `СБРОС`.

Оба действия очищают только локальный список/имена; **WhatsApp-аккаунт, его настоящие контакты, сохранённые сообщения и фотографии не удаляются**. Контакт может появиться снова при новом событии WhatsApp. Очистка **не заставляет WhatsApp заново синхронизировать 20 чатов**.

## Плюсы

- Собственный VPS, доступ из браузера/PWA без отдельного приложения.
- Один WhatsApp-номер, индивидуальный язык и переключатель перевода для каждого собеседника.
- 20 языков; перевод текста и подписей входящих фотографий через Groq.
- Приём и просмотр фотографий; хранение сообщений и фото в SQLite/локальном каталоге с FIFO-очисткой по квоте.
- HTTPS, пароль веб-клиента, автоматический аудит установки, резервные копии с шифрованием.
- На VPS не требуется локальная ИИ-модель.

## Минусы и ограничения

- **Baileys — неофициальный клиент:** возможны отключения, повторная привязка и ограничение WhatsApp-аккаунта.
- **Неполная синхронизация:** WhatsApp может передать меньше 20 чатов, а вместо имён — `@lid` или короткие имена профиля. Сброс контактов этого не исправляет гарантированно.
- Только личные переписки; нет поддержки групп, голосовых сообщений, отправки фотографий, старой истории и нативных push-уведомлений. Одноразовые медиа не сохраняются.
- Для переводов необходим интернет и внешний Groq API: текст переводимых сообщений передаётся стороннему сервису. Действуют его лимиты и тарифы.
- FIFO-удаление освобождает место, но старые локальные сообщения и фото после удаления не восстанавливаются без резервной копии.
- Это MVP: автоматические тесты не гарантируют бесперебойной работы на любом VPS и с любым WhatsApp-аккаунтом.

## Диагностика

```bash
sudo systemctl status whatsapp-translator
sudo journalctl -u whatsapp-translator -n 100 --no-pager
cd /opt/whatsapp-translator && npm run doctor
```

При нестандартном каталоге или имени службы замените пути и имя в командах.
